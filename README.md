## LeetCode Practice

The `leetcode/` folder contains categorized problem-solving practice.

Each solution is intended to include:

- Problem name
- Difficulty
- Topic
- Approach
- Time complexity
- Space complexity
- Code solution

Example format:

```txt
Problem: Two Sum
Difficulty: Easy
Topic: Arrays, Hash Map

Approach:
Use a hash map to store previously seen values and check whether the complement exists.

Time Complexity: O(n)
Space Complexity: O(n)
```
